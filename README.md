# 44th-arma-mods
Arma 3 mod adding pre-configured supply crates for 44th Regiment loadouts. Covers Medical, RANGER (Fire Support, Precision, Anti-Armour, Section), RBN (Sniper, Section, EOD), SFSG (Fire Support, Precision, Section), SRR, and SAS. Crates appear in the Eden Editor under a dedicated "44th Supply Crates" category. Requires UK3CB BAF and ACE.
